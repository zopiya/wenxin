本文展示文心主题支持的常见 Markdown 排版元素，用作样式自查与写作参考。

## 强调层级

文心用不同的线形区分强调层级，而非单纯依赖颜色或加粗：**加粗强调**用实线下划线，*斜体强调*用波浪下划线（CJK 字体的斜体是伪斜切，读起来别扭，所以换成了线形），~~删除线~~表示废弃内容，<u>下划线</u>另作他用，<mark>高亮</mark>标出关键词句。

也支持上标和下标：E = mc<sup>2</sup>，H<sub>2</sub>O。

## 列表

无序列表：

- 第一层
- 第二层
  - 嵌套第二层
  - 再来一条
- 回到第一层

有序列表：

1. 先做这个
2. 再做这个
   1. 子步骤一
   2. 子步骤二
3. 最后做这个

任务列表：

- [x] 已完成的事项
- [ ] 还没做的事项

## 代码

行内代码：`hugo server --disableFastRender`

带语法高亮的代码块：

```python
def fib(n: int) -> int:
    """返回斐波那契数列第 n 项"""
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

## 表格

| 元素 | Markdown 语法 | 说明 |
| --- | --- | --- |
| 加粗 | `**text**` | 实线下划线强调 |
| 斜体 | `*text*` | 波浪线强调 |
| 删除线 | `~~text~~` | 表示废弃内容 |
| 任务列表 | `- [ ] text` | 支持勾选状态 |
